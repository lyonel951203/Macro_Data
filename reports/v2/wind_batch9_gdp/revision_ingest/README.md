## 文件语义（经实证确认，重要）

- **终值列 = 导出当日的现行值**（两文件均延伸到 2026-Q2），不是「修正日期当日可见的序列状态」，不能锚定到修正日期；
- **修正值列非空的行**才记录该修正日期发生的修订事件：值=修正值，生效日=修正日期；
- 两文件终值序列完全一致（0 期差异），且与批次9 MCP 终值拉取吻合，三方交叉验证通过；
- 初值列与库内 A 级官方原值完全一致（如 2022-Q2 初值 0.4 = A 级 0.4），佐证 A 级证据质量。

2. **发现**：vintage 链 sanity 检查（check_gdp_vintage_chain.py）当场暴露未来数据泄漏。

## 复用指引

后续导出其他指标的「历史修正」xlsx 时，直接用 `scripts/ingest_gdp_revision_snapshots.py`
的模式：只取修正值非空行，值=修正值，available_at=修正日期，
release_date_source=wind_revision_snapshot_<日期>。切勿锚定终值列整列。
