# 2026-09-21 分批补缺记录

## 选值规则

- 同一字段、同一数据期只要存在 PIT_A 或 PIT_B，普通 Wind PIT_D 就不进入查询和复合长表。
- Wind 只补没有任何 A/B 记录的字段期；有明确日期的 Wind 修订快照仍作为独立版本事件保存。
- 官方原稿、联合发布方原稿和可核验的政府/媒体完整转载优先升级为 A/B；后来汇编表不能倒填成早期可见版本。

- SAFE 2013-12 的完整披露由人民网保存并明确引用国家外汇管理局数据，六项均已升级为 PIT_B。
