# Wind外贸五项修订链审计（2026-09-21）

## 结论

当前库**没有保存**以下5个指标的Wind历史修订版本：

- `CN_EXPORT_USD`
- `CN_EXPORT_USD_YOY`
- `CN_IMPORT_USD`
- `CN_IMPORT_USD_YOY`
- `CN_TRADE_BALANCE_USD`

库内只保存了2026-09-08导入的一次Wind当前值快照。经验发布日期规则解决了“某月数据大致何时可用”，但没有解决“当时看到的版本与后来修订值不同”的问题。

五个指标的所有记录均为：

- `pit_grade=D`
- `revision_type=initial`
- `release_date_source=NULL`（主库原始记录）
- `available_at=2026-09-08 14:10:31+08:00`
- 每个数据期仅一个版本

复合长表为每个指标生成260个 `selection_origin=WIND` 事件，均无 `valid_to`，没有修订事件链。以2005-01为例，当前快照记录的 `first_seen_at` 是2026-09-08，但复合长表通过 `estimated_availability_sidecar` 将 `valid_from` 回填为2005-02-10。

## 风险判断

- 严格PIT回测风险：**高**。
- 受影响范围：五个字段的全部1,300个字段-数据期均无法证明是当时可见版本。这里不表示1,300个值都实际发生过修订，而是本地没有版本证据区分初值与后续修订值。
- 当前查询会在历史as-of时点使用2026-09-08快照中的修订后值，可能形成前视偏差。
- 这5个字段目前没有A/B官方记录覆盖，复合长表完全依赖Wind D，因此风险不会被更高PIT等级自动消除。

## 建议修复

1. 先将这5项标记为 `CURRENT_REVISED_BACKCAST`，严格PIT模式在2026-09-08之前不使用，研究模式可继续使用并明确警告。
2. 从现在起每日或每次Wind刷新时保存完整快照；同一数据期值变化时写入新的vintage，并将首次观察日作为新版本 `valid_from`。这只能建立未来修订史。
3. 历史修订需要另取Wind历史快照、修订日志或海关历次发布原稿。没有这些证据时，不能准确重建2005年以来的真实版本链。
4. 为这5项增加自动测试：同一数据期值变化必须新增vintage，不得覆盖旧值；严格PIT查询不得在 `first_seen_at` 之前使用无版本证据的当前快照。


## 非Wind来源佐证（2026-09-21补充）

### 官方机制证据

海关总署英文统计页明确区分 Preliminary Release 与 Monthly Bulletin，并说明月度公报经过初步发布后的数据核验，准确性更高；最新月度统计可能与此前发布不同。海关发布日程采用“初步发布—18日月报—20日在线查询”的分阶段结构，并说明核验可持续到年鉴发布。

- 海关总署月度公报入口：https://english.customs.gov.cn/statics/report/monthly.html
- 海关总署初步发布入口：https://english.customs.gov.cn/statics/report/preliminary.html
- 海关统计发布日程示例：https://english.customs.gov.cn/Statics/fc662cee-21c3-474e-a7fb-4768bb1e295a.html

据此推断，Wind在2026-07-18对2026年1—6月六期数据统一更新，高度可能是在吸收海关6月月度公报，而不是Wind独立修改经济数据。要把该推断升级为逐期确定结论，仍需保存7月18日前后的两份海关源文件或Wind快照。

### 数值交叉核对

当前Wind快照中的2026年出口金额当月同比为：1月10.0%、2月39.6%、3月2.5%、4月14.0%、5月19.2%、6月26.9%。

非Wind的GACC衍生月度页面当前显示：

- 1月10.0%、2月39.6%、3月2.5%、4月14.0%、5月19.2%、6月27.0%。
- 来源：https://chinadata.live/china-trade/2026/01/ 至 https://chinadata.live/china-trade/2026/06/ ，其页面标注底层来源为海关总署月度进出口统计。

当时首次发布的媒体记录显示：

- 3月2.5%；
- 4月14.1%；
- 5月19.4%；
- 6月27.0%。

因此4月和5月可以明确看到“首次发布值”与后续GACC衍生当前值不同；6月的26.9%与27.0%差异可能来自底层精度、取整或修订，现有公开页面不足以单独判定。1月和2月首次官方发布以1—2月合计21.8%为主，不能仅靠新闻稿还原两个单月的首次版本。

### 结论边界

非Wind来源足以佐证“海关数据会在月度公报阶段核验修订”以及当前值与初值至少部分不同，但现有在线页面不能完整证明Wind标记的六期逐项旧值、新值和修订幅度。完整历史PIT链需要海关初步稿、18日月报和20日在线查询的逐次归档。
