# 从 2005 年向后逐年补齐的后台任务

用户已授权改为长任务，避免每次只前移几年就结束。队列覆盖 **2005-01-01—2026-07-31**，按年份从早到晚处理七类官方检索，共 **154 个年度检索窗口**；同一窗口的分页自动继续。窗口扫描完成不等于当年所有数据已找齐，重复分页等异常保留待审。

目前已实现的是 **NBS 17 项目标字段的自动发现、正文归档、已核格式的独立验证及缺期追加**。其中 PMI 表格、综合 PMI 当月正文和综合稿明确月度/累计列可通过自动证据门槛；GDP、旧投资分项、未审的房地产旧别名、失业率多月正文等尚未覆盖的格式会记入待审。**PBOC 10 项、SAFE 7 项仍缺历史来源/口径适配，当前后台不会自动把它们补齐。** 这些限制公开保留，不能把 NBS 队列耗尽当作 34 项完成。

每篇先核：归档 SHA256、检索日期与正文真实发布时间一致、明确数据年月、指标/单位/季调/数值、生产解析与独立 lxml 表格/正文证据相同；再核发布前一秒不可见、发布时可见、重复入库无新增。仅自动追加此前严格库不存在的指标月份，已有同月记录不自动改写；未知口径、修订与回算表留待审阅。未用经验滞后倒填 PIT 日期。

每累计新增至少 10 条记录、每个年度窗口结束或任务退出时，自动重导出严格宽表，刷新字段覆盖与起点。全部变化格必须匹配本任务的已保存入库证据及真实可用时间。进度中的新增数量指原始观测数；宽表沿用值不计新历史。

运行行为：

- 独立隐藏 Python 进程，不依赖聊天回合继续；不调用额外模型。电脑保持运行和联网时推进，关机/休眠时不推进；没有安装系统自启动。
- 每次启动最长 **7 天**，队列完成、停止标记、来源封锁或异常会提前结束。2026-09-09 按用户要求取消每日和每轮请求数量上限，按原有限速连续推进；账本继续计数。恢复旧断点时仅清除已解决的预算耗尽错误，其他受阻原因保留。
- NBS 保持单线程、75—105 秒间隔、robots 与 401/403/407/429 熔断。既有 404 不盲目重试。代码/网络异常保留原因并停止，避免带错持续写入。
- 本任务持有现有 NBS 共享锁；同时运行其他 NBS 入库/下载批次前必须先停止它。只读查询可以在它未短暂持有 DuckDB 写连接时执行。

查看 `../../STATUS.md` 顶部的自动更新区块，或 `data/history_backfill/pit_history_autorun.json`。后者含 PID、当前年份/关键词、已完成窗口、每篇原稿结果和待审原因。`receipts/` 保存逐篇独立证据与追加回执；`live_34_field_coverage.csv` 是后台更新的 34 项覆盖；`pit_34_backfill/execution_progress.csv` 保留 B01 时点快照，不能当作后台实时表。

启动/恢复：在项目根目录使用项目 Python 执行 `python scripts/start_pit_history_autorun.py`。本机 PowerShell 禁用 .ps1 文件执行，Python 启动器无需改变系统策略。恢复时沿用队列、原稿缓存、逐篇回执和数据库幂等检查。进程崩溃留下的锁须先核对 PID，确认原进程已结束再清理；来源封锁状态不自动重试。

平缓停止：创建空文件 `data/history_backfill/pit_history_autorun.stop`。任务在当前网络请求/限速等待结束后的检查点退出并释放锁；停止标记保留，防止误启动。再次启动前主动移除这个单一标记文件。

不需要每完成一小批就在聊天中输入“继续”。任务不会自行修改解析代码或解决新口径；这些需要后续代码适配，但不妨碍已支持的年份和指标持续补缺。
