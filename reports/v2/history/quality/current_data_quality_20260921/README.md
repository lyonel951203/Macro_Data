# 当前宏观数据库质量评估（2026-09-21）

## 总体判断

- 结构完整性：高。主库 781,574 行，复合长表 239,942 个事件；版本键、幂等签名、日期、数值、有效区间检查均为 0 个失败，1,414 个原稿引用全部存在。
- 中国复合研究样本：良好。54 个中国月频字段首末区间共 12,392 个字段月份，已覆盖 11,849 个，覆盖率 95.62%；34/54 字段内部完全连续，剩余 543 个缺月均已分类。
- 中国严格 PIT 证据：中等。当前可见中国字段期中 PIT_A/B 占 50.72%，Wind 占 47.94%，SAFE 经验 D 占 1.17%，有日期 Wind 修订占 0.16%。复合回测可用，但严格实时版本研究应筛掉 D/经验来源。
- 美国：良好。18 个字段全部 PIT_B；月频最新期为 2026-06 至 2026-08，季度字段到 2026-Q2。
- 全球：中等偏好。54 个字段中 46 个达到近期月/季覆盖，8 个字段明显陈旧，见 `stale_non_cn_fields.csv`。
- 更新链路：可运行但非全绿。最近中国和全球任务均为 PARTIAL；主要原因是 OECD robots 校验失败和两条已失效 SDMX 路径返回 404。NBS、PBOC 政府转载、MOF、SAFE、RTDSM、ChinaBond、美国财政部和 IMF 最近运行正常或无变化。

## 关键风险

1. 中国剩余 543 个内部空月中，408 个为结构性/早期频率缺口，135 个为财政七项仍无官方或 Wind 值的月份；不应把这些空值自动插值为真实发布值。
2. A/B 与 Wind 的 1,784 个重叠字段期中 1,507 个精确一致（84.47%）。新增财政历史显著增加了当前 Wind 终值与官方初始版本的差异，但 A/B 始终优先；GDP 2013-Q1/Q2/Q3、社融累计 2014-10/11、M2 2009-04 仍需版本证据核实。
3. 8 个国外陈旧字段不能作为当前信号直接使用：印度工业生产、巴西失业率、印度 GDP、日本 CPI、澳大利亚零售，以及法国、意大利、墨西哥 CPI。
4. 外汇储备 140 个 `SAFE_ESTIMATED_D` 事件使用经验可得日，不是原始实时版本；可按 `selection_origin` 单独排除。
