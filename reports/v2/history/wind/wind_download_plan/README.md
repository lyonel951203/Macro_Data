# Wind 补数清单与 PIT 处理建议

2026-09-08 更新：已收到首批 Excel，并接入 8 项、1,958 条 PIT_D 当前历史记录。最新处理结果和后续下载项见 [首批接入说明](../wind_batch1/README.md)、[剩余七项目标](../wind_batch1/next_download_7.csv)。下文为首批交付前的计划快照；实际接入入口为 `scripts/review_wind_batch.py`，估计可用日期视图仍未实现。

Wind 适合补齐数值历史。只有“数据期—当前值”的时序，不能通过经验日期变成严格 PIT：实际发布时间和当时发布的数值版本都需要证据。本文是接入方案，尚未实现 Wind 导入或估计可用日期视图，也未修改主库 PIT 规则。

下载清单按项目 2026-09-08 第四批（13:17）已入库覆盖制作；第五批 NBS 后台任务仍在运行，清单中的当前计数是一份冻结快照。候选未下载不等于官方数据不存在；“难以获得”指当前项目的抓取/证据缺口。

## 导出要求

- 时间：2005-01（GDP 为2005-Q1）至最新已公布；晚于2005才有记录的指标从其首期开始，不补零。
- 原始月/季频率，保留空值，不插值、不前向填充、不把季度扩展为月份。若方便，也可导出更早历史。
- 保留 Wind 代码、完整名称、单位、频率、原始来源、季调与统计口径说明、实际导出时间。原始 Excel 宽表可以直接保留，无需按模板手工转置。
- 当月、累计、余额、增量、同比、环比必须分清；GDP 目标为当季不变价同比；同比指数（上年同月=100）与同比增长率（%）不能直接混用。
- 如新旧统计口径、初步值/修订值可分别选择，请分开导出；1—2月合并发布保留原样。
- 原始文件可放在 `data/manual_import/wind/`。目前只准备了清单及表头模板，后续依实际导出格式完成映射与导入。

## 发布时间与版本

建议保留三个用途层次：

1. 严格 PIT：官方原始发布值和发布时间证据，继续使用项目 A/B 标准。
2. Wind 当前历史：作为数值覆盖及研究对照；若只有当前/修订值且无版本证据，按 D 保存，`first_seen_at` 为项目实际归档时间，真实 `available_at` 不向过去回填，`release_at` 未知则为空。导出时间单独保存。
3. 估计可用日期研究视图：另行实现 `estimated_available_at`、`availability_method=estimated`、`availability_rule_version`、`vintage_status=latest_snapshot`。从可核对的历史发布日或发布滞后规则产生日期，按指标和时期分组，显式保留例外。它不进入严格 PIT，也不改变 D 记录的真实可用时间。

经验可以用来提出滞后假设，之后应用已验证发布样本校准，并测试更晚可用日期的情景。多滞后若干天或一个月只能缓解发布时间错位，不能证明修订后数值在过去已经可见。未来定期冻结每次 Wind 导出，可以从开始留档之日起积累版本，不能追溯生成已遗失的历史版本。

当前项目只接受 A/B/C/D；不要直接加不存在的 E 等级，也不要把猜测日期填成 C 或 A/B。参见项目 README 的 PIT grades 和 `db.py` 中 D 的可用时间约束。

实际例子：本项目已核对的2021-Q3 GDP原始稿数值为4.9%；2026年二季度发布稿附的历史表中，2021-Q3为5.5%。给后者配上2021年的发布日期，并不能还原当时的信息。原值证据见 [第四批验证记录](../nbs_gap_batch4/validated_samples.csv)，修订后历史表见[国家统计局2026年二季度发布稿](https://www.stats.gov.cn/sj/zxfbhjd/202607/t20260716_1964142.html)。

M1同样要保留口径：央行从2025年1月启用修订口径，并列出按可比口径回溯的2024年余额与增速；这些回溯值不能因补上2024年的日期就成为当时版本。见[央行货币供应量表及注释](https://www.pbc.gov.cn/diaochatongjisi/attachDir/2025/11/2025111913535682666.pdf)。

## Wind 可进一步核实的能力

Wind 官方 EDB 说明包含全球经济日历，可查看经济数据公布时间。值得先在终端核实历史日历的覆盖年限、能否导出，以及是否包含事件对应的当时公布值和修订记录。官方公开介绍没有证明当前账号拥有完整历史 vintage 功能；不能据此假定具备或完全没有。见[Wind EDB 官方说明](https://www.wind.com.cn/portal/zh/EDB/index.html)。
