# 第42轮：统计局英文历史发布补证

从英文历史目录 index_31.html 找到并归档2008年二月工业、社零两篇官方原稿；来源、SHA256与原文在sources.json。BeautifulSoup与lxml分别验证正文期间和页面发布时间。

工业稿发布时间2008-03-13 13:25，正文15.4%明确为一至二月累计；社零稿2008-03-12 13:52，20.2%也为一至二月累计。标题中的February不能作为单月口径证据，两篇均未用于补二月单月，也不足以证明当年没有单月发布。

工业稿的历史图片已归档，JPEG文件头正常，但本轮图像查看工具失败，尚未视觉核验。不得将它计为已解析，也未从图片提取任何数值。后续优先读取该图并沿英文历史目录查2005—2007年原稿，避免重复中文标题搜索。
