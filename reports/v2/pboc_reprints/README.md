## 自动任务范围

接入后使用独立的 `config/pboc_reprint_pull.json`，SAFE 的原配置及断点不迁移。央行队列保留旧归档和受阻记录，加入已发现正文与 2005—2026 年六个关键词的 132 个年度检索窗口。检索页记录命中数并继续分页，只从实际搜索结果提取财政部财经视点正文 URL，不构造文章编号。

单个检索窗口最多 100 页，总队列最多 1,500 个 URL，达到限制明确记为待复核，不宣称历史完整。年份不匹配、网页格式异常均隔离该窗口，不记为“无结果”。请求每日和每轮次数不限，仍保留来源间隔、robots、缓存及 HTTP 熔断。既有 7 天截止期限保留。

此任务只归档，不写主库。搜索结果日期仅作为索引证据，不直接成为 PIT 标签。原发时间、转载时间、数据期、人民币/本外币、单月/累计、全国/地方口径后续独立核验；不能用经验日期或 URL 日期倒填 PIT。转载文字也可能含笔误，下载成功不等于数值可入库。

迁移入口 `scripts/activate_pboc_reprints.py` 先验证实测通过及原稿哈希，备份旧配置和状态，再追加新队列；[迁移结果](activation.json) 仅在实际接入后生成。实时运行状态见 [监控](../source_monitor/latest.md)。
