# PIT_work 按时点可见与修订语义

日期：2026-09-16。

## 当前规则

1. 每个 `as_of` 截点只使用当时已经可见的记录。
2. 每个字段先选择最新可见的数据期；不能因为更高等级的记录较旧，就长期停留在旧数据期。
3. 同一数据期内，普通 Wind/SAFE 终值只在没有可见 A/B 时使用，并按规则表估计发布日期后移。
4. 带 `wind_revision_snapshot_*` 的 Wind 修订事件使用有据修订日：修订日前返回原有 A/B，修订日后返回修订值；其后若出现更晚的官方版本，可再次替代。
5. `work_origin` 区分 `work_A`、`work_B`、`work_wind`、`work_wind_revision`、`work_safe_d`。
6. strict 仍保留为 A/B-only 审计基准；月末宽表 CLI 默认改为 `work`。
7. work 宽表字段集合取最终截点实际可见的全部 A/B/Wind/SAFE 字段，不再由 strict 的 A/B 字段集合裁剪。
