# 第26轮：早年工业发布制度

国家统计局2024年《什么是工业生产增长速度》明确说明2005年取消一月报表，以及2012年取消二月当月速度。原文已归档并用BS4/lxml核验。对2006—2011一月增加缺少的规则，当前内部待核实际减少4条；不把规则推广到零售、不排除2011年及以前二月。12项测试通过，入库0。

发现2005-01已有20.9%记录与回溯制度说明冲突。核读当时原稿，确实写明一月同比20.9%、按日均水平调整8.9%，不能判定为解析错误，禁止猜测更改日期或删除。官方原稿冲突见official_conflict.json；2005豁免未应用。此冲突不在缺失行统计中，必须作为第一阶段额外未决，不能在141个缺失行解决后自动忽略它。

目前116条历史日历+25条合并期未决，另1项官方证据冲突。第1项尚未完成，后续阶段等待。下一轮优先核对2005工业原稿的原始年份及制度实际起点，然后早年零售/房地产。主库和数值宽表未修改。
