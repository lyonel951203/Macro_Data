新增2013-12七个真实字段月份：工业增加值同比9.7%、零售名义同比13.6%、CPI同比2.5%、PPI同比-1.4%；固定资产投资累计同比19.6%、房地产开发投资累计同比19.8%、制造业投资累计同比18.5%。全年值仅用于12月累计字段，单月字段只读明确12月份句。没有使用全年CPI2.6/PPI-1.9，也未将零售实际增速12.2替代名义值。

来源为第19轮已归档NBS官方全年稿，A类可用时间2014-01-20 10:00。两套HTML解析及逐句统计范围核验、隔离试入、幂等性、旧记录保留及14次PIT边界检查通过；主库771832、中国11098，严格宽表已刷新。

CPI/PPI真实月份117/122，2005-01至2026-06分别仍缺141/136个月。制造业投资首个PIT月末前移至2014-01-31，但只补一个真实累计期，长期连续历史未完成。其他指标remaining_months.csv是未应用发布日历豁免的原始日历差集，不能全部认作漏数；制度调整后缺口见calendar_adjusted_continuity.csv。日历正常不发布计数112→120来自制造业投资观察范围扩大，不是新增8条制度证据。305处宽表变化含前向填充。

PMI2010-04/05本轮搜索未找到新的同期官方原稿，保留之前6月稿中5月历史列的较晚证据，不倒填PIT日期。下一轮按队列处理SAFE口径变化分界及附件；之后扩展NBS综合稿同类漏字段，批量扫描须包含第19轮新归档文件（未在旧NBS URL缓存命中）。
