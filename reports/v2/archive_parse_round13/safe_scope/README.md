# SAFE历史涉外收付款口径差异

本轮离线比对194篇原稿定义、原稿SHA均通过。以下是已归档页面观察到的文字分组范围，不是已证实的制度生效日期：

- 19篇，2010-03-31至2011-12-28：境内收付款包括外汇收付款及跨境贸易人民币结算项下的人民币收付款。
- 161篇，2012-01-21至2025-07-22：暂不包括境内居民个人与境内非居民个人之间的人民币收付款。
- 13篇，2025-08-15至2026-08-17：暂不包括境内居民个人和机构与境内非居民个人之间的人民币收付款。
- 1篇其他文字待核，见evidence.json。

2015-02-16制度说明称在现有口径及种类基础上增加子项目，并将更新2010年以来历史数据；不能据此认定历史原稿与更新历史序列完全等价。

受影响：CN_CROSS_BORDER_RECEIPTS_USD、CN_CROSS_BORDER_PAYMENTS_USD、CN_CROSS_BORDER_NET_RECEIPTS_USD。已有严格库也跨越这些文字分界；目前期数连续仅指观察期连续，不保证同口径。calendar_adjusted_continuity.csv处理的是发布日历，不包含本口径门槛，验收须结合scope_warning.json。旧数据未删除或改值；本轮不向这些字段追加早期原稿。
